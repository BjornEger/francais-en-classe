# Le français à portée de main

Un tableau de bord français-danois pour retrouver rapidement des mots pendant les cours.

## Contenu

- 69 verbes : présent, passé composé et futur proche.
- 64 adjectifs : formes masculines, féminines et plurielles.
- Nombres cardinaux et ordinaux, années, surfaces (m²), volumes (m³) et devises ; conversion de 0 à 1 000 000.
- 313 expressions et mots utiles, dont 232 fiches dans six rubriques : vacances, météo, immobilier, restaurant, travail et carrière, football.
- Adverbes et repères : temps, lieu, fréquence et autres expressions, avec exemples danois.
- Pronoms personnels (sujet, COD, COI, toniques), réfléchis, y/en et possessifs ; tableaux comparatifs et exemples.
- Recherche en français et en danois, filtres et favoris.

Ouvrir `index.html` dans un navigateur. Aucun service externe ni installation n’est nécessaire. Les favoris sont enregistrés dans le navigateur ; la lecture audio utilise uniquement les voix françaises disponibles sur l’appareil ou dans le navigateur, avec priorité au français de France. Une voix anglaise ne sera jamais utilisée comme solution de repli.

## Hébergement GitHub Pages

Dans **Settings → Pages**, choisir **Deploy from a branch**, puis la branche contenant ces fichiers et le dossier **/(root)**. Le fichier `.nojekyll` permet de servir directement les fichiers.

Le site publié avec GitHub Pages est public. Les favoris restent enregistrés localement et ne sont pas partagés avec d’autres visiteurs.
